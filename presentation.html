01. Overview & Motivation

Problem Statement & Project Vision.

Legacy System Pitfalls

The Challenges

  • • Sluggish & Cluttered Interfaces: Traditional booking sites are heavy, ad-ridden, and lack intuitive user flow.
  • • Inventory Inconsistencies: Slow database synchronization leads to seat contention and double-booking errors.
  • • Difficult Cancellations: Most platforms bury ticket cancellation behind multi-step support tickets without instant seat return.
  • • Disjointed Administration: No unified dashboard for cinema managers to curate film schedules and seat quotas.
The CineBook Solution

Our Vision & Objectives

  • ✔ End-to-End CRUD Lifecycle: Full control over movie schedules, seat updates, and instant bookings.
  • ✔ Atomic Seat Restitution: Automatic decrement on reservation and immediate refund back to inventory on cancellation.
  • ✔ Warm Editorial Aesthetics: Inspired by HealthTwin with sunset orange accents, Fraunces serif typography, and 3D parallax effects.
  • ✔ Verified Admission Passes: Generates instant digital passes with perforated styling, showtimes, and barcode references.

06. Workflow Engineering

Technical Workflow: Ticket Booking.

Step 01

User Selection

User chooses movie, showtime, enters name and specifies seat count.

Step 02

Axios Dispatch

Client transmits async POST request payload to /api/bookTicket.

Step 03

Server Validation

Express verifies movie existence and checks: availableSeats >= requested.

Step 04

Atomic Save

Decrements movie seats and persists new Booking document into MongoDB.

Step 05

Pass Issuance

Client generates verified digital ticket pass with cutouts and barcode.

07. Workflow Engineering

Technical Workflow: Ticket Cancellation.

Stage 01

Cancel Intent

User clicks Cancel button on active ticket in /bookings view.

Stage 02

Modal Safeguard

ConfirmModal prompts confirmation to prevent accidental cancellations.

Stage 03

Status Shift

Express verifies active state, changes status = 'Cancelled'.

Stage 04

Seat Restitution

Locates movie by movieId; adds seats back: seats += booking.seats.

Stage 05

Client Sync

Client receives success message; auto-reloads lists and updates badges.

10. Problem Solving

Technical Challenges & Engineering Solutions.

Challenge 01

Inventory Contention & Overbooking

Risk of multiple users booking the same last seats simultaneously.

Solution: Pre-save validation verifies availableSeats >= requested before decrementing inventory.
Challenge 02

Two-Way Collection Synchronization

Cancelled bookings must reliably return seats back to movie capacity.

Solution: Cancellation endpoint matches movieId and increments availableSeats += seats.
Challenge 03

React 19 StrictMode & Effect Cascades

Linter warnings regarding synchronous setState execution inside useEffect.

Solution: Migrated to functional initializer callbacks and achieved 0 warnings across all 22 files in Oxlint.
Challenge 04

Fixed Header Navigation Collision

Fixed glassmorphic header created overlapping content collisions on inner pages.

Solution: Calibrated padding-top: 78px with tight container padding for a snug, balanced layout.
