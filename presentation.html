01. Overview & Motivation

Why We Built CineBook — The Problem & Our Solution.

The Daily Booking Struggle

Legacy System Pitfalls

  • • Crowded & Slow Interfaces: Cluttered layouts with overwhelming banners and complicated checkout steps.
  • • Confusing Seat Statuses: Delayed synchronization causes seats to show available when already taken.
  • • Painful Cancellation Flows: Cancelling tickets usually involves support tickets or lost seats with no immediate refund.
  • • Zero Admin Clarity: Cinema owners lack a fast, clean dashboard to adjust schedules and capacities.
How CineBook Fixes It

Our Vision & Approach

  • ✔ Instant, Distraction-Free Booking: Pick your movie, pick your seats, and get your pass in seconds.
  • ✔ Live Seat Balance: Capacity updates immediately so guests always see true availability.
  • ✔ 1-Click Friendly Cancellations: Free up seats immediately back to the cinema with a single click.
  • ✔ Straightforward Movie Management: Add, edit, or remove movies with live feedback on all screens.

06. Booking Workflow

What Happens When You Book — 5-Step Booking Flow.

Step 01

Pick & Fill

Choose movie, showtime, enter name and seat count on the booking form.

Step 02

Quick Check

Frontend verifies inputs and sends async POST request to /api/bookTicket.

Step 03

Safe Reservation

Express verifies movie exists and checks: availableSeats >= requested.

Step 04

Update & Save

Decrements seat stock and creates a confirmed booking document in MongoDB.

Step 05

Ticket Ready

Displays styled admission pass with barcode and show details immediately.

07. Cancellation Workflow

What Happens When You Cancel — 1-Click Seat Restitution.

Stage 01

View Ticket

User visits /bookings and spots their active reservation pass.

Stage 02

Double-Check

Confirmation modal pops up to prevent accidental ticket cancellations.

Stage 03

Status Change

Server sets status to 'Cancelled', preserving the historical record.

Stage 04

Give Seats Back

Exact seat count is added right back to the movie: seats += booking.seats.

Stage 05

Instant Sync

Screen refreshes immediately with updated badges and restored seat totals.

10. Problem Solving

Real Engineering Problems We Solved — And How We Fixed Them.

Challenge 01

Seat Overbooking

Risk of multiple users grabbing the same last seats simultaneously.

How We Solved It: Server verifies availableSeats >= requested before decrementing inventory.
Challenge 02

Returning Seats Upon Cancellation

Cancelled bookings must reliably add seats back to the movie capacity.

How We Solved It: Cancellation endpoint atomically finds the movie and adds seats back: seats += booking.seats.
Challenge 03

React 19 State Cascades

Linter warnings regarding synchronous setState execution inside useEffect.

How We Solved It: Refactored to functional state initializers, achieving 0 warnings across all 22 files in Oxlint.
Challenge 04

Clean Screen Layout

Fixed glassmorphic header created overlapping content collisions on inner pages.

How We Solved It: Calibrated padding-top: 78px with tight container padding for a snug, balanced layout.
